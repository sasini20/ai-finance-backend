# AI Finance Tracker - Backend

This is the backend server for the **AI Finance Tracker** application, built using **Node.js**, **Express.js**, and **MongoDB**. It handles secure RESTful APIs, database operations, user authentication, and Google Gemini AI integration for smart transaction categorization.

## 🚀 Features
- **AI Integration:** Powered by Google Gemini AI to automatically categorize transactions and detect types.
- **Authentication & Security:** Secure JWT authentication and password hashing (bcrypt) with password reset functionality.
- **RESTful Architecture:** Clean modular routing and controllers for user management and financial records.
- **Database Persistence:** Mongoose ODM for structured data handling with MongoDB.

## 🛠️ Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (Mongoose)
- **AI Engine:** Google Generative AI (Gemini API)
- **Hosting:** Railway
